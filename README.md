## How I work

- **Tickets before code.** Every change starts with a scoped ticket and explicit done criteria.
- **A ship gate that is not me.** A zero-context reviewer and QA runner must both clear the work before merge.
- **Verify the artifact, not the log.** I check what actually shipped after deployment.
- **Every miss becomes a rule.** Bugs and agent missteps become permanent system improvements, recorded in each repository’s `EVOLUTION.md`.
